# dw-cli

The `dw` command-line tool for PowerPoint (`.pptx`) presentations. It provides
`inspect`, `check`, `roundtrip`, and `query` commands, plus a JSON-lines `serve`
mode.

```sh
cargo install dw-cli
dw check presentation.pptx --json
```

See the [repository](https://github.com/JoaoCodificacoes/deckwright) for command
details and current verification status.
