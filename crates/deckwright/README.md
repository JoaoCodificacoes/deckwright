# deckwright

Rust library for creating editable PowerPoint (`.pptx`) presentations and
inspecting their package structure, animations, and slide state. It can import,
check, query, and write OOXML presentations.

See the [repository](https://github.com/JoaoCodificacoes/deckwright) for usage
examples and current verification status. PowerPoint playback equivalence has
not yet been established for every animation feature.
