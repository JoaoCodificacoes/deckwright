# Deckwright agent guidance

When creating or editing a PowerPoint deck with Deckwright, read
[`skills/deckwright-presentations/SKILL.md`](skills/deckwright-presentations/SKILL.md)
before authoring slides. It adapts the former `morph-deck` Python authoring
workflow to Deckwright's Rust APIs and current verification tools.

For framework changes, follow the repository's existing plans, tests, and
acceptance gates. A package check or static render alone does not establish
PowerPoint animation playback.
